# SETUP / TEARDOWN

[Shared Link](https://mirri.link/Tt-bnbT)

---

## MEDIA (5–7 min)

**Setup**
1. Log in → TableChurch102  
2. Back TV ON  
3. 2 Audience TVs ON  
4. ProPresenter ON → wait for camera preview  

**Teardown**
1. Quit ProPresenter  
2. TVs OFF  
3. Lock Screen (⌃⌘Q)  

---

## AUDIO (8–10 min)

**Setup**
1. Wi-Fi: The Table / TableChurch102  
2. Amp ON (booth cabinet)  
3. Stage Monitors ON (front switches)  
4. Mixing Station → Full Mix → Search → XR18  
5. Fresh batteries in all mics  
6. Soundcheck → Gain in green–yellow (~ -15 dB)  
7. Aux 3+4 = Monitors / Aux 1+2 = In-Ears  
8. Walk stage → check musician mixes first, then house  

**Teardown**
1. Mute Bass channel  
2. Stage Monitors OFF  
3. Amp OFF  
4. Batteries back on charger  

---

## MUSICIANS (3–5 min each)

**Setup**
- Check mic batteries  
- **Acoustic**: Xvive U2 → receiver in DI, transmitter in guitar, switch = mute  
- **Bass**: leave gain alone, unmute only when amp ON  

**Teardown**
- Return all batteries to charger  
- **Acoustic**: power off, paddle back on charger  
- **Bass**: mute channel before amp OFF
