# Processing Cheat Sheet
*(workflow for fast, consistent mixes)*

---

## VOCALS

1. **Tone** → Neve 1073  
2. **Shape** → SSL 4K B (light compression)  
3. **Color** → choose ONE  
   - Saturn 2 (warmth)  
   - Decapitator (grit)  
   - RC-20 (vibe)  
4. **Compression**  
   - 1176 (fast, 3–5 dB)  
   - LA-2A (slow, 2–3 dB)  
5. **Cleanup** → Pro-Q (cuts only)  
6. **FX** → sends  
   - Valhalla Room (tight)  
   - VintageVerb (long)  
   - Delay (1/4 or 1/8)  
7. **Optional Polish** → Neutron Sculptor (very light)

---

## VOCAL BUS

- Neve 1073 (subtle drive)  
- 1176 slow **or** API 2500 (gentle glue)  
- Pultec EQP-1A (tiny sweetening)

---

## DRUMS — INDIVIDUAL

### Kick / Snare
1. SSL 4K B (main tone + punch)  
2. Pro-Q (cleanup)  
3. Neutron Transient Shaper (if needed)  
4. 1176 (2–4 dB)

### Overheads / Rooms
1. Neve 1073  
2. Pro-Q (tame harshness)  
3. Light comp (API or LA-2A)

---

## DRUM BUS

1. SSL 4K B Bus Comp (2–4 dB)  
2. API 2500 (slow attack glue)  
3. Saturation (Saturn 2 or Decapitator)  
4. Ozone Imager (very subtle width)

---

## BASS

1. Neve 1073 (body)  
2. Pro-Q  
3. 1176 (fast)  
4. LA-2A (slow)  
5. Saturn 2 (harmonics)

---

## ELECTRIC GUITARS

1. Neve 1073  
2. Pro-Q  
3. (Optional) Light compression  
4. Color → choose ONE  
   - RC-20  
   - Saturn 2  
   - SketchCassette II  
5. (Optional) SSL 4K B for presence

---

## ACOUSTIC GUITAR

1. Neve 1073  
2. Pro-Q (remove boxiness)  
3. LA-2A or Avalon (light)  
4. Valhalla Room (small)

---

## KEYS / PADS / SYNTHS

1. Neve 1073 (warm) **or** SSL (bright)  
2. Pro-Q  
3. Movement → ShaperBox (if needed)  
4. Long/wide verb (VintageVerb or Supermassive)

---

## MIX BUS (Pick ONE)

### A) Neve Bus (warm + musical)
- 1073 (tiny drive)  
- API 2500 (2–3 dB)  
- Pultec EQP-1A  
- Ozone Maximizer

### B) SSL Bus (punch + clear)
- SSL 4K B comp (1–2 dB)  
- Pultec EQP-1A  
- Ozone Maximizer

---

## PARALLEL CHAINS

### Parallel Vocals
- 1176 all-buttons  
- Decapitator (mix 10–20%)

### Parallel Drums
- 1176 all-buttons **or** API 2500 (hard)  
- Blend to taste

---

## RULE OF THUMB

**One color plugin per track.**  
No RC-20 + Decap + Sketch + Saturn stack.  
Pick one. Commit.
