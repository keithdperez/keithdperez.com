# Mixing Workflow

## 1. Prep & Rough Balance
- Import stems, name & color-code.
- Group into: **Drums / Bass / Guitars / Vocals / FX**.
- Start from silence → bring up the most important element (drums or vocal).
- Use only **faders + panning** here.
- Goal: 80% of the mix feels balanced before touching plugins.

---

## 2. Core Tonal Work
**Keep inserts minimal.** Only EQ/compress if absolutely needed.

- **EQ (surgical cuts only):** FabFilter Pro-Q 4 or Neutron EQ
- **Compression (for control, not hype):**
  - Drums → API 2500 (glue/punch)
  - Bass → LA-2A (level) + optional API 2500 (tightness)
  - Vocals → LA-2A → 1176 (control + energy)

👉 Ask: *Does this track really need it, or can the group bus handle it?*

---

## 3. Buss Processing (Glue & Tone)
This is where “pro” mixes come from. Don’t sauce every track—sauce the bus.

- **Drum Bus** → API 2500 (glue) → Decapitator (subtle drive)
- **Guitar Bus** → SSL 4K B (slight EQ lift + grit)
- **Vocal Bus** → LA-2A (smooth) → Decapitator (mix knob ~10–20%)
- **Mix Bus (light touch only, not mastering)** → SSL 4K B (tiny push) or Shadow Hills (gentle glue)

---

## 4. FX (on Sends, Not Inserts)
- **Reverb (space):** ValhallaVintageVerb (plate/room for drums, hall for vocals/guitars)
- **Delay (movement):** EchoBoy or stock delay (slap + long stereo)
- **Parallel Comp:** 1176 all-buttons or API 2500 on a send, blend in for drums/vocals
- **Optional Texture:** Saturn 2 or RC-20 on a bus for lo-fi grunge layers

---

## 5. Build the Mix
- **Drums + Bass first** → low-end foundation.
- Add **vocals** → make sure they sit without EQ acrobatics.
- Layer **guitars/synths** around vocals → carve small EQ holes (2–5k for vocal presence).

---

## 6. Translation Checks
- Bounce a draft early.
- Listen on AirPods, laptop, car.
- Fix only the issues that repeat across systems.

---

## 7. Final Polish
- **Automation > Compression** for movement.
- Listen whisper-quiet for balances, loud for harshness.
- **Mix print for band:** Ozone Maximizer at -3dB headroom.
- **Mastering prep:** No limiter, leave -6dB headroom.

---

## 8. Core Plugin Set (Keep It Simple)
**EQ & Dynamics**
- FabFilter Pro-Q 4
- UAD API 2500
- UAD LA-2A / 1176 (Gray)

**Tone & Saturation**
- SoundToys Decapitator
- UAD SSL 4K B

**FX**
- ValhallaVintageVerb
- EchoBoy (or stock delay)

**Mastering / Checks**
- Ozone 11 Maximizer (drafts only)

---

## Mindset
- **Balance first, plugins second.**
- **Groups > individual tracks.**
- **Less sauce = more pro.**
- **Reference tracks every 10–15 min.**
