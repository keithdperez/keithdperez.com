# Agent Guidelines for Keith's Obsidian Vault

## File Organization
- **Daily notes**: `/daily/` with format `YYYY-MM-DD.md`
- **Templates**: `/templates/` for reusable note structures (daily-note, meeting_note, etc.)
- **MOCs** (Maps of Content): `/moc/` for framework notes that link related concepts
- **Private**: `/private/` for sensitive or personal content
- **Attachments**: `/attachments/` for images, audio, PDFs; `/attachments/excalidraw/` for drawings

## Naming Conventions
- Use lowercase with spaces for readability: `presence & posture.md`, `file naming convention.md`
- Daily notes: strict `YYYY-MM-DD.md` format
- Descriptive, question-based titles welcome: `why do I exist?.md`, `what makes me feel alive.md`
- For music projects, see `/file naming convention.md` for detailed versioning rules

## Content Style
- **Tone**: Personal, reflective, direct. This is a private notebook with public-facing notes in `index.md`
- **Structure**: Use frontmatter for metadata (publish, title, description); horizontal rules `---` for section breaks
- **Links**: Use Obsidian's `[[wikilinks]]` for internal references; preserve existing link structure
- **Templates**: Daily notes use Templater syntax (`tp.date.now()`) and Things app integration (`things:///`)

## When Editing
- Preserve existing voice and writing style (conversational, spiritual, technical mixed)
- Maintain MOC linking patterns (e.g., `Presence & Posture.md` links to theme clusters)
- Keep daily note format consistent with template structure
- Don't create new folders without explicit direction—use existing organizational structure
